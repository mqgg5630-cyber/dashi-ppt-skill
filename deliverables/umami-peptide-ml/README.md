# 机器学习筛选鲜味肽

这是使用 Dashi PPT Skill 生成的 15 页科研方案概念设计稿，主题为 `theme07` 冷白调研风。

## 文件

- `ppt/index.html`：可在浏览器打开并编辑的 HTML 演示文稿
- `goal.json`：可复现的 schema v2 生成计划
- `content-briefs.json`：逐页研究内容 brief
- `ppt/assets/user-media/`：AI 生成并嵌入的科研插图

## 说明

本稿表达的是研究方案与实验闭环设计，不宣称已经取得实验结果。页面内的候选、模型和验证指标需要结合实际数据、实验条件和文献继续校准。

打开 `ppt/index.html` 后可直接改字、换图、切换版式；在本机安装 Chrome / Chromium / Edge 后，可按仓库说明导出可编辑 PPTX。
